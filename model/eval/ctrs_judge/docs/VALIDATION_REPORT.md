# CTRS 평가 모델 검증 결과 (LLM-as-a-judge)

작성 시점: 2026-10 기준 실험 결과. 수치는 모두 이 레포의 코드로 재현 가능한 실행 결과에서 가져옴. 사람(교수님) 채점과의 비교는 아직 수행하지 않았음.

## 1. 목적과 범위
- 목적: 상담 챗봇(베이스, 파인튜닝)을 정량 지표로 비교하기 위한 평가 모델을 먼저 만들고, 그 평가 모델이 쓸 만한지 검증함
- 평가 방식: CACTUS 선행 연구와 같은 CTRS 6개 항목 프롬프트로 LLM이 대화 전문을 읽고 0~6점(정수)과 설명을 출력함
- 이 문서의 범위: 평가 모델의 검증 결과와 최종 설정의 근거. CTRS 및 6개 항목 선정 이유는 팀 보고서 본문에서 서술함

| 구분 | 항목 |
|---|---|
| 일반 상담기술 | 이해, 대인관계 효과성, 협력 |
| CBT 기술 | 유도된 발견, 핵심 인지와 행동 초점, 변화전략 |

## 2. 최종 선정 결과
| 구분 | 선정 |
|---|---|
| 판정 모델 | gpt-6.1-sol (reasoning effort low, temperature 미적용) |
| 프롬프트 | CACTUS 원본에서 엄격도 지시만 제거한 버전(`prompts_relaxed/`) |
| 비교 기준 | CACTUS 원본 엄격 프롬프트(`prompts/`)도 함께 보고함 |

- 엄격도 지시: 원본 프롬프트 단계 3의 "grading very strictly. If there is any deficiency, no matter how minor, assign a score of 4 or lower."(CBT_1은 마지막 줄 "Do not forget to give a score strictly and uptight."도 포함)
- 평가 질문, 점수 기준(0, 2, 4, 6, 중간은 홀수), 출력 형식은 원본과 동일함
- 판정 설명은 한국어로 받음(`--lang ko`, system 지시로만 지정하며 프롬프트 원문은 수정하지 않음)

## 3. 실험 설계
### 3.1 평가 대상 데이터
- 원본: 번역 정제한 CACTUS 한국어 1000개 중 무작위 20개(seed 0)
- 망가뜨린 대화: 원본 중 10개의 상담자 발화만 일부러 품질을 낮춤(내담자 발화와 첫 인사는 유지)
- 정도별 변형: 유형마다 대화 1개(5개)에 대해 상담자 발화의 30%, 60%만 망가뜨린 버전 10개
- 차가운 태도 변형: 공감 제거에 무뚝뚝한 말투를 더한 대조 버전 4개

| 유형 | 방식 | 점수 하락을 기대하는 항목 |
|---|---|---|
| 반복 | 첫 탐색 질문을 이후 발화에 그대로 반복 | 이해 |
| 공감 제거 | 발화에서 마지막 문장만 남김 | 대인관계, 이해 |
| 차가운 태도 | 공감 제거 + 무뚝뚝한 한마디 | 대인관계 |
| 일방적 지시 | 선택권 없이 지시하는 템플릿 문장으로 교체 | 협력 |
| 설교 | 질문 대신 단정하고 반박하는 템플릿 문장으로 교체 | 유도된 발견 |
| 잡담 | 핵심 인지와 무관한 잡담 템플릿 문장으로 교체 | 핵심 초점 |

- 템플릿 3종(일방적 지시, 설교, 잡담)은 내담자 말과 무관한 문장이라 대화 흐름이 부자연스러움. 결함이 뚜렷한 상황을 만드는 1차 검증용임
- 같은 원본에서 만든 변형끼리 비교하므로 소재 차이의 영향을 제거한 짝 비교임

### 3.2 비교 대상과 실행
| 구분 | 내용 |
|---|---|
| 판정 후보 | gpt-6-luna(reasoning none, temperature 0), gpt-6.1-sol(reasoning low, temperature 미적용) |
| 엄격 프롬프트 실행 | 44개 대화, 두 모델, 1회차 264호출/모델, 원본 10개는 3회 반복(총 384호출/모델) |
| 완화 프롬프트 실행 | sol만, 30개 대화(원본 20 + 망가진 100% 10), 원본 10개는 3회 반복(총 300호출) |
| 파싱 | 모든 호출 성공(파싱 실패 0, API 실패 0) |

## 4. 결과
### 4.1 망가진 대화를 걸러내는가
- 정도 100%에서 기대 항목 점수가 모든 건에서 하락함(두 모델 모두 12건 중 12건, 완화 sol은 10건 중 10건)
- 기대 항목 평균 변화(원본 대비): luna -3.90, sol -3.33(엄격), sol -4.08(완화)
- 판정 결과가 대부분 0~2점으로 내려가, 품질이 심하게 낮은 대화는 확실히 걸러짐

### 4.2 망가진 정도에 비례해 내려가는가
기대 항목 평균 변화(엄격 프롬프트, 정도별)

| 모델 | 30% | 60% | 100% |
|---|---|---|---|
| luna | -1.81 | -2.64 | -3.90 |
| sol | -1.67 | -2.17 | -3.33 |

- 두 모델 모두 정도가 클수록 점수가 단계적으로 내려감
- 유형별(n=1, 100%는 n=2)로는 편차가 있음: 반복 sol -2.0, -3.0, -3.5, 잡담 sol -1.0, -2.0, -4.0은 매끄럽게 내려감
- 잡담 30%, 60%에서 luna의 핵심 초점은 원본 단일 채점과 같은 4점에 머묾(sol은 3점, 2점)

### 4.3 항목별로 정확히 짚는가
- 기대 항목이 나머지 항목보다 더 내려가는 정도(특이성)는 약함
  - 엄격: luna 기대 -3.90 / 나머지 -3.32, sol -3.33 / -2.71(정도 100%)
  - 완화(sol): 기대 -4.08 / 나머지 -3.70
- 원인: 상담자 발화를 망가뜨리면 대화 전체 품질이 같이 떨어지므로 항목이 함께 하락함. 항목별 민감도를 엄밀히 보려면 더 정교한 변형이나 사람 채점이 필요함
- 예외적으로 반복 30%에서 luna는 이해만 2점으로 내리고 나머지는 4점을 유지함(사례 1건)

### 4.4 공감과 따뜻함을 잡는가
- 공감 제거(정중한 질문만 남김): 엄격 프롬프트에서는 대인관계가 거의 내려가지 않음(sol 변화 없음). 완화 프롬프트에서는 대인관계가 5→4, 6→4로 내려감
- 차가운 태도(100%): 대인관계가 luna 5.7→0, 6→2, sol 4→0, 4→0으로 크게 하락함
- 해석: 눈에 띄는 차가움은 두 모델 모두 잡고, 은근한 차이는 완화 프롬프트에서 감지됨. 은근한 차가움에 대한 정밀한 검증은 남아 있음

### 4.5 같은 대화를 다시 채점해도 같은 점수인가
| 모델, 프롬프트 | 평균 표준편차 | 점수가 달라진 조합 |
|---|---|---|
| luna, 엄격 | 0.16 | 22%(60개 중 13개) |
| sol, 엄격 | 0.01 | 2%(1개) |
| sol, 완화 | 0.05 | 12%(7개) |

- sol은 temperature가 적용되지 않는데도 거의 흔들리지 않음. 달라진 건은 모두 1점 차이임
- luna의 불안정은 luna가 4점을 넘게 준 칸(5, 6점)에 집중됨. 4점일 때는 안정적임

### 4.6 모델 비교 요약 (엄격 프롬프트 기준)
| 항목 | luna | sol |
|---|---|---|
| 정상 대화 120칸 중 5~6점(1회차) | 45칸(37.5%) | 0칸 |
| 일관성(평균 표준편차) | 0.16 | 0.01 |
| 100% 변형 기대 항목 하락 | 12/12 | 12/12 |
| 비용(40개 1회) | 약 $0.05 | 약 $1.12(약 22배) |
| 지시 준수 | 낮음(4점 초과 다수) | 높음 |

- 모델 간 일치(엄격, 264칸 비교): 정확히 같음 63%, ±1점 이내 78%, 평균 차이 luna-sol +0.47점
- luna는 점수 폭이 넓지만 일관성이 낮고 4점을 넘기는 점수가 불안정함. sol이 판정 모델로 더 안전하다고 판단함

### 4.7 엄격도 지시 제거의 영향 (sol, 정상 20개 120칸)
| 프롬프트 | 3점 | 4점 | 5점 | 6점 | 평균 | 표준편차 | 서로 다른 점수 수 |
|---|---|---|---|---|---|---|---|
| 엄격(원본) | 5 | 115 | 0 | 0 | 3.96 | 0.20 | 2 |
| 완화 | 2 | 49 | 54 | 15 | 4.68 | 0.71 | 4 |

정상 대화 항목별 평균

| 항목 | 엄격 | 완화 |
|---|---|---|
| 이해 | 3.95 | 4.00 |
| 대인관계 | 4.00 | 5.40 |
| 협력 | 4.00 | 4.90 |
| 유도된 발견 | 3.90 | 4.40 |
| 핵심 초점 | 4.00 | 4.95 |
| 변화전략 | 3.92 | 4.45 |

- 엄격 프롬프트는 정상 대화의 96%를 4점으로 만들어 좋은 대화끼리 구분하기 어려움. 완화하면 점수가 4~6점으로 퍼짐
- 망가진 대화(100%, 10개, 기대 항목 12칸): 엄격 -2.75(10/12 하락), 완화 -3.58(12/12 하락). 기준점이 높아져 하락폭이 커 보이는 효과가 일부 섞임
- 대가: 평균이 +0.72 올라 상단 천장(대인관계 5~6점 집중)이 생김

### 4.8 퍼진 점수가 신호인가
- 일관성: 완화 sol의 표준편차 0.05로 잡음은 작음
- 독립 judge와의 순위 일치(정상 20개, luna 엄격 vs sol 완화, 출력 표의 소수 첫째 자리 값으로 계산)

| 항목 | 순위 상관(Spearman) |
|---|---|
| 변화전략 | 0.86 |
| 핵심 초점 | 0.65 |
| 협력 | 0.52 |
| 대인관계 | 0.33 |
| 대화별 합계(이해 제외) | 0.73 |
| 이해, 유도된 발견 | 계산 불가(한쪽 judge가 모든 대화에 같은 점수) |

- 프롬프트와 모델이 모두 다른 judge끼리 정상 대화의 순서가 상당히 일치하므로, 완화 점수의 차이는 대화 품질 차이를 반영할 가능성이 높음
- 단, 두 judge가 같은 편향을 공유할 가능성은 배제하지 못하며, 정답 기준은 사람 채점임
- 재현: `python3 compare_judges.py results/run1.jsonl gpt-6-luna results/relaxed.jsonl gpt-6.1-sol` (도구 계산값은 반올림 차이로 소수 둘째 자리가 다를 수 있음)

## 5. 최종 선정 근거
1. 판정 모델 sol: 지시를 지키고(5~6점 남발 없음), 반복 채점에서도 안정적이며(표준편차 0.01~0.05), 정도별 하락이 단계적이고, 핵심 초점 등 일부 항목에서 luna보다 변별이 나음
2. 완화 프롬프트: 정상 대화의 점수를 4점 하나에서 풀어 구분 가능성을 확보하고, 망가진 대화 검출(12/12)과 은근한 공감 제거 감지가 유지 또는 개선됨. 원본 엄격 프롬프트는 비교 기준으로 병기함
3. 비용: sol이 luna의 약 22배이므로 대규모 실행은 Batch API 또는 캐시를 활용하고, 탐색 단계에서는 소규모 샘플을 사용함

## 6. 한계
- 사람(전문가) 채점과의 일치도를 아직 확인하지 않음. 교수님 검토가 필요함
- 이해 항목은 완화 후에도 정상 대화 모두 4점으로, 좋은 대화끼리의 구분력이 없음. 6점 기준에 비언어적 반응이 포함되어 텍스트만으로는 상한이 막힌 것으로 추정함
- 유도된 발견은 비교 judge(luna)가 모두 같은 점수를 줘서 교차 확인이 불가능함
- 항목 특이성이 약해 항목별 점수를 독립 지표로 단정하기 어려움
- 망가뜨린 대화는 템플릿 중심이라 부자연스러움. 정교한 변형(LLM 재작성 등)은 미실시이며, 변화전략을 겨냥한 변형도 없음
- 완화로 평균이 4.68로 올라 상단 천장이 생김. 좋은 챗봇 응답에서 점수가 5~6점에 몰릴 수 있음
- 번역 데이터(한국어)와 원문 영어 프롬프트의 조합이며, 영어 원문 대화와의 점수 차이는 검증하지 않음
- 정상 20개는 GPT가 생성한 이상적인 합성 대화이므로 실제 챗봇 대화에서는 분포가 달라질 수 있음

## 7. 향후 과제
- 교수님 검토: 대표 사례(원본, 망가진 대화) 10개 안팎에 대해 판정 점수와 설명의 타당성 확인
- 챗봇 대화(베이스, 파인튜닝)에 같은 파이프라인 적용. 대화 텍스트만 jsonl 형식으로 바꾸면 됨
- CTRS 점수가 높은데 실제로는 반복이 심한 사례가 나오면 계산형 보조 지표(반복률 등) 추가 검토(`extra_metrics.py`)

## 8. 재현 방법
```bash
cd model/eval/ctrs_judge
pip install -r requirements.txt            # .env에 OPENAI_API_KEY 설정
python3 make_perturbations.py              # 평가 대화 생성(키 불필요)
python3 run_eval.py --input datasets/eval_set_30.jsonl --all --out results/final.jsonl            # 최종 설정(sol, 완화)
python3 run_eval.py --input datasets/eval_set_30.jsonl --all --prompts-dir prompts --out results/strict.jsonl   # 원본 엄격 프롬프트
python3 summarize.py results/final.jsonl
python3 compare_runs.py results/strict.jsonl results/final.jsonl --judge gpt-6.1-sol
```
