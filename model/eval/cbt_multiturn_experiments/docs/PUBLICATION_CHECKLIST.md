# GitHub 공개 전 확인

## 공개 후보로 정리한 범위

- 연구 흐름·확인된 문제·미확정 원인·실험 한계.
- 허용 목록으로 선택한 코드·프롬프트·모델 다운로드 메타데이터.
- 원문이 없는 집계 지표와 최소 실행 설정, 파일 해시·출처.
- 가짜 생성기를 이용하는 형식·연결 테스트.
- 사용자가 공개 대상으로 승인한 CACTUS 합성 사례 R002·R004의 전체 턴별 대화 결과. AIHub 실제 상담 발화는 제외했다.

## 포함하지 않은 것

- `.env*`, API 키, Hugging Face 토큰, Jupyter 연결 토큰, 개인 연결 URL.
- AIHub 원본·정제 상담 대화, 내담자 프로필, 별도 사례 입력 파일, 학습/검증/테스트 JSONL.
- `raw_calls.jsonl`, 실제 세션·발화 CSV/JSONL, 승인된 두 CACTUS 사례 이외의 전문 대화록.
- 어댑터·모델 가중치, 토크나이저 캐시, 다운로드 자산, 대용량 압축 파일.
- 결제·계정 화면, GPU 콘솔 스크린샷, 실행기 전체 로그, 임시 노트북 페이로드.
- 자문 요청 초안·연락처 등 실험 공개에 필요 없는 개인 문서.

## 남은 사람의 검토

- [ ] 연구팀의 코드 공개 동의와 권리 관계 확인. 라이선스는 임의로 부여하지 않았다.
- [ ] 데이터셋 이용·재배포 조건과 모델별 라이선스 확인. 원문 공개 제외가 모든 권리 문제의 해결을 뜻하지는 않는다.
- [ ] 과거 공개 자료를 참고한 프롬프트·기법 목록의 출처 표기 확인.
- [ ] 코드·프롬프트를 읽어 자동 검사에서 놓칠 개인정보나 민감한 내용이 없는지 확인.
- [ ] “진단 실험”, “CTRS 평가”, “전문가 검수 예정/완료”의 표현을 구분했는지 확인.
- [x] 사용자가 지정한 GitHub 저장소에 PR로 제안한다. 2026-10-08 최초 준비 단계에서는 commit·push·PR을 하지 않았다.
- [ ] 실제 업로드 전 staging 목록과 diff를 확인. 프로젝트 전체를 `git add .`로 올리지 않는다.

원래 로컬 작업공간의 `.gitignore`는 비공개 원본 폴더를 제외한다. 원본은 삭제하지 않았다. 대상 저장소에는 이 아카이브만 별도 하위 폴더로 추가하며, 기존 앱 코드와 데이터 저장 정책을 변경하지 않는다. 대화 결과는 진단 실험의 검토 자료이지 배포용 데이터셋이 아니다.

자동 검증 통과는 검토를 돕는 검사 결과이지, 비밀·개인정보 부재나 법적 공개 적합성을 보증하는 인증이 아니다.
