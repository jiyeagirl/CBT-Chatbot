# 재현 범위와 코드 읽기 안내

## 버전의 의미

- `code/`에는 허용 목록에 선택한 당시 실행 사본 또는 당시 보관 아카이브의 코드가 있다. 생성 manifest가 소스 해시를 기록한 실험은 대조해 불일치 시 정리를 중단한다.
- 해시가 없는 과거 runner는 **보관 사본**일 뿐 실제 실행 바이트의 완전 일치를 증명하지 않는다. GPT 상담자 스크립트는 현재 보관본이고 실행 당시 소스 해시가 없어 별도로 표시했다.
- `analysis_tools/`는 지금 보관한 비교·감사 도구다. 실제 생성 코드의 역사적 버전으로 주장하지 않는다. 기존 프로젝트의 상대 경로와 비공개 원본을 전제로 하는 도구는 공개 폴더에서 바로 실행되지 않는다.
- 소스·프롬프트는 임의로 수정하지 않고 바이트 그대로 복사했다. 알려진 결함은 실행 기록과 노트로 설명한다. 공개 폴더 구성을 위해 경로를 고친 새 실행기로 포장하지 않는다.

## 필요한 비공개 자료

과거 결과의 완전 재계산에는 적법하게 확보한 CACTUS/AIHub 자료, 같은 전처리·선택 결과, 고정 내담자 입력 또는 내담자 프로필, 실제 어댑터, 원시 요청·응답이 필요하다. 이 자료는 공개 아카이브에 포함하지 않았다. 실험별 입력 해시는 동일성 확인용이며 입력을 복원하지 못한다.

가중치 이용 조건을 임의로 재허가하지 않는다. 사용자가 승인한 CACTUS 합성 사례 두 개의 결과만 검토 자료로 포함하며, AIHub 실제 상담 원문과 전체 학습 자료는 제외한다. 데이터셋 이용·재배포 조건은 별도 확인이 필요하다. 두 사례 이외의 원문을 공개 저장소에서 확인할 수 없다는 재현 한계도 명시한다.

## GPU/API 없는 검증

아카이브 루트에서 다음 명령은 파일 해시, JSON 구조, Python 구문, 공개 제외 패턴, 상대 문서 링크를 검사한다.

```bash
python3 tools/validate_archive.py
```

기존 가짜 생성기 테스트를 읽거나 실행할 수 있다. 모델 품질이 아니라 연결·이력 보존·출력 처리 테스트다.

```bash
PYTHONPATH=code/qwen_replay_20261007:analysis_tools python3 -m unittest discover -s tests -v
```

실행 결과와 검증 범위는 `verification.json`을 참고한다. 생성 스크립트, 설치·배포 스크립트, GPU 다운로드는 이번에 실행하지 않았다.

## 이후 실제 재실행할 때

1. 실험의 `record.json`에서 해당 코드 세트, 정확한 프롬프트, 생성 조건과 입력 해시를 선택한다.
2. 해당 runner의 `--help`/소스에서 필요한 파일과 CLI를 확인하고, 별도 비공개 작업 폴더에 준비한다. 하드코딩된 원래 프로젝트 배치를 쓰는 도구도 있다.
3. 필요한 라이브러리는 당시 runtime을 우선 확인한다. 학습 아카이브의 requirements는 학습 당시 자료이며, 모든 후속 GPU/API 실험의 단일 lockfile이 아니다.
4. 새 결과 폴더에 저장한다. 과거 로그를 덮어쓰지 말고 원문·길이 종료·실제 생성 설정·모델 revision·프롬프트·코드 해시를 기록한다.
5. 실제 실행에는 비용 승인과 독립적인 시간/종료 장치가 필요하다. 이 공개 아카이브 자체는 RunPod를 관리하지 않는다.

모델별 sampling override는 `model_config.json`을 확인한다. E11의 원본 manifest 안내에는 과거 Q4_0 문구가 남아 있으나 실제 설정은 Q4_K_M이었다. 공통 generation 기본값만 보면 sampled 조건을 잘못 읽을 수 있으므로 config의 모델별 sampling을 우선한다.
