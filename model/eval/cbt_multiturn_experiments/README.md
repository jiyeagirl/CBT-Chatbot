# CBT 상담 모델의 멀티턴 반복 문제 · 실험 아카이브

정리일: 2026-10-08 · 연구용 한국어 정서 지원 프로토타입

## 무엇을 기록하는가

처음에는 Qwen3-8B에 CBT 지침을 적용한 조건과, 같은 조건에 CBT QLoRA를 추가한 조건의 대화 품질을 비교하려 했다. **멀티턴 대화록을 읽으면서 내담자의 반응이 바뀌어도 상담자가 비슷한 탐색 질문과 개입 제안을 되풀이하는 문제가 드러났다.**

내담자 시뮬레이터를 바꾸고, 상담 계획·상태 관리 기능을 시험하고, 프롬프트를 완화하거나 전환 예시를 넣었다. 이후 다른 기반 모델도 같은 고정 내담자 발화로 비교했다. 일부 국소 개선은 있었으나, 원하는 대화 진행과 적절한 CBT 개입을 안정적으로 확보하지 못했다.

이 아카이브의 목적은 최종 우승 모델을 발표하는 것이 아니라, **무엇을 바꿨고, 무엇을 관찰했으며, 왜 아직 원인을 하나로 확정하기 어려운지**를 코드·프롬프트·실행 기록과 연결하는 것이다.

## 읽는 순서

1. [실험 흐름](docs/EXPERIMENT_HISTORY.md): 문제 발견 → 원인 가설 → 변경 → 관찰 → 남은 의문.
2. [실제 전체 대화 결과](docs/DIALOGUE_RESULTS.md): CACTUS R002·R004의 조건별 내담자 발화와 생성 응답. AIHub 원문 제외.
3. [실험 인덱스](experiments/INDEX.md): 실험별 코드 경로, 프롬프트, 설정, 집계 결과.
4. [프롬프트 이력](docs/PROMPT_HISTORY.md): 실제 보존된 지침과 변경 diff.
5. [재현 안내](docs/REPRODUCIBILITY.md): 당시 실행 사본과 현재 분석 코드의 차이, 필요한 비공개 입력.
6. [공개 전 점검](docs/PUBLICATION_CHECKLIST.md): 공개 제외 범위와 아직 필요한 사람의 검토.

## 반드시 구분할 것

- `base`는 이 기록에서 **CBT 추가 파인튜닝 어댑터를 적용하지 않은 조건**을 뜻한다. 후보 중에는 이미 지시학습된 Instruct/IT 모델이 있으므로 순수 pretrained base 모델과 같은 뜻이 아니다.
- `system-prompt-only`는 CBT 프롬프트만 적용한 조건이다. `plan-state-v2`는 별도 계획·메모 생성 호출까지 포함한다. 코드에 기능이 존재한다고 모든 실험에서 실행한 것은 아니다.
- 대부분의 후속 비교는 학습 노출 사례의 **고정 발화 재생 진단**이다. 내담자는 새 상담자 응답에 적응하지 않고, 원본의 호전 발화는 새 모델의 효과가 아니다.
- 물음표·같은 질문 문자열·완전 중복은 참고 지표다. 질문 감소가 곧 상담 개선은 아니며, 표현만 바뀐 의미 반복과 응답 내부 반복도 따로 읽어야 한다.
- 정식 CTRS 점수, 전문가 평가 결과, 임상적 효과 또는 배포 안전성 검증을 완료한 기록이 아니다. PANAS는 포함하지 않았다.

## 폴더 구조

```text
docs/                  연구 흐름, 프롬프트 이력, 재현·공개 안내
experiments/           실험별 record.json, README, 프롬프트·모델 설정
code/                  당시 실행 사본; 동일한 코드 세트는 여러 실험이 공유
analysis_tools/        현재 보관 중인 분석·비교 코드; 실행 당시 버전과 구분
tests/                 GPU/API 없는 연결·형식 테스트
tools/                 공개 아카이브 검증기
provenance.json        파일 출처·해시·검증 상태
CHECKSUMS.sha256        공개 파일 무결성 확인값
```

코드는 역사적 실행 사본을 보존하므로 알려진 실패 경로도 그대로 남아 있다. 공개 데이터 이용권한·비공개 입력·어댑터·GPU 또는 API 설정 없이 전체 생성 실험을 바로 재실행할 수는 없다. 기존 원본은 이동·삭제·수정하지 않았다.

로컬 구조 검증:

```bash
python3 tools/validate_archive.py
```

이 명령은 모델 다운로드·학습·API 호출·RunPod 배포를 하지 않는다.
